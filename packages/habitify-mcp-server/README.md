# @sargonpiraev/habitify-mcp-server

MCP server for Habitify habit tracking API

## Install

```bash
npm install -g @sargonpiraev/habitify-mcp-server
```

## Home

This package lives in the public monorepo:

https://github.com/sargonpiraev/packages/tree/main/packages/habitify-mcp-server

## Run

```bash
npx @sargonpiraev/habitify-mcp-server
```

Configure API credentials via environment variables (see `.env.example` when provided).
