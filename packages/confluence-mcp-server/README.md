# @sargonpiraev/confluence-mcp-server

MCP server for Confluence Cloud REST API

## Install

```bash
npm install -g @sargonpiraev/confluence-mcp-server
```

## Home

This package lives in the public monorepo:

https://github.com/sargonpiraev/packages/tree/main/packages/confluence-mcp-server

## Run

```bash
npx @sargonpiraev/confluence-mcp-server
```

Configure API credentials via environment variables (see `.env.example` when provided).
