# @sargonpiraev/gitlab-mcp-server

MCP server for GitLab API

## Install

```bash
npm install -g @sargonpiraev/gitlab-mcp-server
```

## Home

This package lives in the public monorepo:

https://github.com/sargonpiraev/packages/tree/main/packages/gitlab-mcp-server

## Run

```bash
npx @sargonpiraev/gitlab-mcp-server
```

Configure API credentials via environment variables (see `.env.example` when provided).
