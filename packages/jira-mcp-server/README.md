# @sargonpiraev/jira-mcp-server

MCP server for Jira Cloud REST API

## Install

```bash
npm install -g @sargonpiraev/jira-mcp-server
```

## Home

This package lives in the public monorepo:

https://github.com/sargonpiraev/packages/tree/main/packages/jira-mcp-server

## Run

```bash
npx @sargonpiraev/jira-mcp-server
```

Configure API credentials via environment variables (see `.env.example` when provided).

## Release

Published from the [`sargonpiraev/packages`](https://github.com/sargonpiraev/packages) monorepo via Trusted Publishing (`on-push-main.yml`).
