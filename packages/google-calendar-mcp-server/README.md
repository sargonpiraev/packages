# @sargonpiraev/google-calendar-mcp-server

MCP server for Google Calendar API

## Install

```bash
npm install -g @sargonpiraev/google-calendar-mcp-server
```

## Home

This package lives in the public monorepo:

https://github.com/sargonpiraev/packages/tree/main/packages/google-calendar-mcp-server

## Run

```bash
npx @sargonpiraev/google-calendar-mcp-server
```

Configure API credentials via environment variables (see `.env.example` when provided).
